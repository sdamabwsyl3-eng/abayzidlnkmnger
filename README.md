أبا يزيد لنك منجر — تطبيق مفتوح المصدر مصمم خصيصاً لمشغلي الشبكات المحلية ومقدمي خدمة الإنترنت.

الميزات الرئيسية:
🔌 إدارة كاملة لجهاز MikroTik — مراقبة العملاء والباقات والاتصالات
💳 إنشاء وطباعة كروت الاشتراك الحرارية مباشرة من التطبيق
📦 متجر خدمات — باقات Starlink وأجهزة الشبكات ومستلزمات الطباعة
📊 لوحة تحكم إحصائية — عدد العملاء، الباقات الفعالة، حالة النظام، عدد الطباعات
📚 مركز مساعدة — دروس خطوة بخطوة وأسئلة شائعة وحل المشاكل الشائعة

التقنيات المستخدمة: Flutter • Dart • GitHub Actions
